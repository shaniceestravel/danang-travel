# 岘港遗产列车之旅

2026年11月10日至14日，5天4晚。岘港、会安、顺化旅行手账网页。

## 使用

用浏览器打开 `index.html`。HTML、CSS 和 JavaScript 均包含在这个文件中，照片以同目录下的 JPG 文件加载。无需安装依赖或构建。

## 功能

- 每日行程和日期切换
- 去程 AK642、回程 AK643 航班信息
- 景点与体验照片、餐食及酒店安排
- 景点顺序示意图（非实际地理定位或导航）
- 行囊清单，勾选状态保存在当前浏览器
- 在概览页打印或保存完整行程为 PDF

## 图片与资料

照片取自用户提供的旅游行程资料；发布者需确保具有相应使用授权。行程、住宿、餐食和航班以旅行社及机票最终确认为准。
